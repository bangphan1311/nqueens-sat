# Exploratory runs

This directory contains preliminary pilot and scout runs used during
benchmark development and solver/encoding selection.

These files are retained for transparency and provenance. They are not
part of the main E1-E5 result tables unless a paper section explicitly
identifies and discusses an exploratory result.

- `pilot.csv`, `pilot2.csv`, `pilot_cpsat.csv`: preliminary pilot runs
- `scout.csv`, `scout.log`: short scout runs used to investigate
  candidate configurations

The reported benchmark datasets and their environments are documented
in the repository-level `README.md` and `PROTOCOL.md`.
